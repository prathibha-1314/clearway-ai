ClearWay AI

AI-Powered Emergency Traffic Management Platform

ClearWay AI is a hackathon project that intelligently creates a **Dynamic Temporary Emergency Corridor (DTEC)** to help ambulances navigate traffic faster.

Core Features:

-  Live Ambulance Tracking
-  Route Prediction
-  AI Vehicle Relevance Scoring
-  Dynamic Temporary Emergency Corridor (DTEC)
-  Smart Driver Notifications
-  AI Dashboard
-  Real-time Simulation

Tech Stack:

Frontend
- React
- Next.js
- Tailwind CSS
- TypeScript
- Google Maps

Backend
- Node.js
- Express.js
- Firebase

AI & Simulation
